# Harmony 原生浏览器服务端核心（未接入）

此目录提供 DSH 工具适配器、中继和独立测试。`apply()` 默认不注册工具；显式启用时，插件从应用私有目录按需读取短期中继凭据。

浏览器确认是否弹出由调用会话的实时权限预设决定：只有 `auto` 与 `danger-full-access` 跳过原生确认，其余（含 `custom`、服务缺失或异常）一律要求原生确认。预设只从 `permissionPresets.current(agent.session)` 读取，不接受工具参数、网页或 GUI 自报；调用开始时不是自动模式的请求，即使中途切换也不会自动放行。该判定不能消除检查与执行之间的跨进程竞态。当前原生授权界面及文件权限验证尚未完整接入或真机验收，不能仅凭加载插件、页面 JavaScript、回环地址或请求中自报的身份认定其安全。运行 `node --test plugins/dsh-harmony-browser/*.test.mjs plugins/dsh-harmony-browser/*.test.cjs plugins/dsh-harmony-browser/test.mjs`；宿主测试不运行 ArkWeb。

## 未来接入契约

宿主须建立可信进程内能力或具有操作系统级对端身份验证的 IPC，绑定具体应用实例、浏览器实例、用户会话和生命周期；不存在时保持关闭。不要把此模块直接封装成无认证 localhost HTTP 接口（本机其他进程或网页可能访问）；WebSocket、HTTP、ArkWeb JS bridge 都不天然提供可信身份。可行候选是由原生宿主持有不可由网页调用的受限消息通道，在其服务端适配层验证身份、完整性、生命周期和请求关联；具体平台能力尚未验证，不宣称现已可用。

当前 `apply(ctx, {enabled: true})` 注册工具并通过私有文件提供器按需读取凭据；中继进程负责创建和清理该文件。代码已接入随包资源和显式安装路径，但真实 DSH profile 解析与设备文件权限仍未验证。中继使用受凭据保护的 loopback TCP 和原生进程 stdin/stdout，`sessionId` 只是标签，不能证明会话归属或原生审批。`createBrowserCore` 是独立队列原型，不是此中继的授权证明。

工具适配器要求引擎提供 `exec.agent`，并通过 `ctx.agents.get(agent.id) === agent` 检查调用时是否是当前存活的对象，再将该对象原样传给绑定层。这只检查入口时刻，不保证会话在排队或授权期间仍然存活，也不自动绑定浏览器实例；绑定层必须在授权与执行时重新验证。

`authorize(request, {signal, agent})` 必须在可信原生 UI 中针对每次 open/observe 展示真实目标、实际访问数据和用户会话，并只在用户明确同意时返回严格的 `true`；拒绝、取消、失联均失败。`execute` 只能对已授权绑定实例执行对应动作，返回不超过 65536 UTF-16 单元的文本。它必须实现可靠请求关联、超时及取消，且失败返回前确保原生端不会继续执行；若无法确认执行状态必须销毁绑定并阻止后续操作。此核心在活动请求取消或超时后永久关闭，不假定 abort 已使原生操作停止。断连、窗口变更、授权撤销、宿主关闭也必须主动关闭核心。工具结果是网页提供的不可信内容，不是指令。

## 文件信箱实验（未接入）

`mailbox.js` 是独立的同 UID 信箱实验，不注册工具或启用 ArkTS 操作。它使用预先存在的可信私有目录、单一 `active` 槽、随机请求 ID、截止时间和不可覆盖的原子文件发布；取消、超时或异常后持久写入撤销标记并保留槽，恢复前必须停止两端并人工检查。它要求本地文件系统支持硬链接及目录 fsync；ArkTS 对端及真机能力均未验证。撤销检查到操作开始之间仍有竞态，已开始的操作也无法靠文件撤销，因此不能据此承诺严格取消或安全重试。不得直接将该模块视为已完成的授权或会话绑定通道。

`mailbox-v2.js` 是另一项未接入的协议实验，探索独占目录认领、原子 rename 与完成标记，以减少 ArkTS 对硬链接的依赖；它不是可直接启用的生产传输。`entry/src/main/ets/platform/BrowserMailbox.ets` 仅定义手动调用的接收状态机和异步后端契约，没有可运行的 CoreFileKit 后端，也没有接入页面。宿主测试使用 Node 模拟双方，不证明 ArkTS 文件 API、断电持久性或严格取消。实验已加入消息大小、格式及截止时间检查，但仍需实现可信会话绑定，并在目标系统验证原子性、持久性和生命周期，才能考虑接入。

`observe.js` 是尚未注入 ArkWeb 的只读观察实验；它不读取表单当前值或 Cookie，但页面文本、标题和 URL 仍可能包含敏感数据。可见性检查不是安全边界，不能代替用户授权，也不覆盖 iframe、shadow DOM 或画布。

## 安全限制

只接受 HTTP(S) URL 且禁止 URL 凭据；这不是网络隔离：本机、内网地址、DNS 重绑定、重定向、页面脚本、下载和外部协议仍需原生端按安全策略处理。授权必须覆盖最终跳转/重定向与用户隐私；observe 可能泄露登录状态、页面秘密或个人数据，需独立同意、最小化输出并限制敏感字段。无点击、输入、脚本执行、截图或任意原生命令能力。队列上限包括活动请求，超时从入队起算；活动请求被取消即熔断，防止与未知仍运行的原生动作重叠。所有绑定方法属于可信代码；本模块不验证调用方身份，也不能保证用户授权或强制原生端正确执行。未做真机或 IPC 验收。
